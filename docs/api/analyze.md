# Analyze (Sobol)

`jaxgsa.sobol.analyze()` computes variance-based Sobol indices (`S1`, `ST`,
and the optional `S2`) from model outputs evaluated on a Saltelli design built
by `jaxgsa.sobol.sample()`.
